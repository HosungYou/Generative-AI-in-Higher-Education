## Data Extraction Checklist

For each PDF retrieved, extract:

```
□ Full citation (authors, year, title, journal, DOI)
□ Sample size (N total, n treatment, n control)
□ Study design (RCT, quasi-experimental, other)
□ GenAI tool used (ChatGPT-3.5, GPT-4, Claude, other)
□ Intervention duration (weeks)
□ Academic discipline
□ Country/region
□ Outcome measures (cognitive, affective, metacognitive, behavioral)
□ Statistical data:
  □ Means and SDs (if reported)
  □ F-statistics, t-statistics, p-values
  □ Effect sizes (if reported)
  □ 95% confidence intervals
□ Notes on limitations or special considerations
```
