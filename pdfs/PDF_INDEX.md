## File Naming Convention

```
##_FirstAuthor_Year_ShortTitle.pdf
```

- `##`: Two-digit sequential number (01-65)
- `FirstAuthor`: Last name of first author (or journal abbreviation if unknown)
- `Year`: Publication year (2024 or 2025)
- `ShortTitle`: Abbreviated descriptive title
